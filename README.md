# 나만의 룩북 · LOOKBOOK STUDIO

모델 사진을 가운데, 옷 사진을 양옆에 3개씩 배치하는 가상 피팅 룩북입니다. 옷을 클릭하면 **본인 PC의 AI**가 착용 사진을 만들고, 모델 아래에서 해당 상품의 **쿠팡 링크**를 열 수 있습니다.

사이트: https://mkj5956.github.io/Cookbook-site/

## 처음 사용하기

1. 이 저장소의 **Code → Download ZIP**을 누르고 압축을 풉니다.
2. `local-ai/0_CHECK_PC.bat`를 더블클릭해 PC 사양을 확인합니다.
3. `local-ai/1_INSTALL.bat`를 실행합니다. Python 3.11/3.12가 없으면 Windows 패키지 관리자로 Python 3.12 설치를 시도합니다. 프로그램과 AI 파일을 받는 첫 설치에는 인터넷이 필요합니다.
4. `local-ai/2_START.bat`를 실행합니다. PC AI와 연결된 GitHub Pages 사이트가 열립니다. 실행 창을 닫으면 AI도 종료됩니다.
5. Chrome에서 **로컬 네트워크 접근** 안내가 나오면 허용합니다.
6. 가운데에 모델 사진, 양옆에 옷 사진을 등록합니다. 옷마다 종류·사진 형태·상품명·쿠팡 링크를 입력하고 옷 카드를 클릭합니다.

처음 설치한 뒤 인터넷 없이 화면까지 PC에서 열려면 `3_OFFLINE.bat`를 실행하세요. 공개 사이트와 오프라인 사이트는 저장공간이 다르므로 **프로젝트 저장 → 불러오기**로 작업을 옮길 수 있습니다.

## 기능

- 모델 사진과 6개 의상 사진 업로드, 상의·하의·원피스 AI 가상착용
- 상품 단독 사진 또는 다른 사람이 입은 사진 지원
- 옷마다 쿠팡 상품/공유 링크 등록, 모델 아래 및 내 룩북에서 링크 열기
- 현재 룩에 다른 옷 추가, 원본/결과 비교, 생성 취소, 결과 PNG 저장
- 완성한 룩 최대 20개 브라우저 보관, 프로젝트 파일 백업/복원

## 공개 사이트와 PC AI

GitHub Pages는 화면을 제공하는 정적 호스팅입니다. Python이나 GPU AI를 실행하지 않습니다.

| 구성 | 실행·저장 위치 |
| --- | --- |
| 공개 화면 파일 | GitHub Pages |
| 모델·옷·완성 룩 | 본인 브라우저, 직접 저장한 프로젝트 파일 |
| 가상착용 AI | 본인 PC의 `127.0.0.1:8765`, 실행 중 메모리 |
| AI 모델 파일 | 본인 PC의 `local-ai/weights`, `local-ai/cache` |
| 쿠팡 링크 | 프로젝트에 포함, 클릭할 때 쿠팡 이동 |

사진을 GitHub나 외부 AI API로 보내지 않습니다. 공개 URL을 보내도 **내 사진·내 룩북은 공유되지 않습니다.** 다른 방문자가 AI를 쓰려면 그 방문자의 PC에도 AI 프로그램이 필요합니다. 설치 시에만 GitHub/PyPI/PyTorch/Hugging Face에서 프로그램과 AI 파일을 받으며, 합성할 때는 오프라인 모드를 사용합니다.

연결 코드는 실행할 때마다 바뀌며 URL의 `#` 뒤로 전달한 직후 주소에서 제거합니다. 탭 세션에만 보관하며 프로젝트 파일이나 저장소에는 넣지 않습니다. 서버는 `127.0.0.1`에만 열리고 허용된 사이트와 연결 코드가 있는 요청만 받습니다.

## PC 조건과 한계

- 윈도우 10/11 64비트, Python 3.11 또는 3.12
- 이 패키지 대상: NVIDIA RTX 30 시리즈 이상
- 모델 공식 안내: 약 8GB VRAM. 이 구성은 **12GB 이상 권장**이며 8GB에서 메모리 부족이 생길 수 있습니다.
- 여유 기준: 시스템 RAM 16GB 이상, 설치 디스크 여유 15GB 이상 권장. 실행을 보장하는 사양은 아닙니다.
- 최신 NVIDIA 드라이버가 필요합니다. 실행 가능 여부와 속도는 GPU/드라이버마다 다릅니다.
- FASHN VTON 1.5 기본 생성 캔버스는 576×864입니다. 원본 비율에 맞춰 여백을 제거하므로 최종 크기는 달라질 수 있습니다.
- 실제 사이즈·핏을 측정하지 않습니다. 얼굴, 체형, 로고, 무늬가 달라지거나 원래 옷의 흔적이 남을 수 있습니다. 반복 합성은 오차를 늘릴 수 있습니다.
- 브라우저 데이터를 지우면 룩북도 사라집니다. ‘프로젝트 저장’으로 백업하세요.
- 쿠팡 가격·재고·이미지를 자동 수집하지 않습니다. 직접 등록한 링크로 이동합니다.

## GitHub Pages 배포

저장소 **Settings → Pages → Build and deployment → Source → GitHub Actions**로 설정합니다. `main`에 저장하면 `.github/workflows/pages.yml`이 테스트 후 `web/`만 배포합니다. AI 가중치·캐시·가상환경·개인 사진은 배포하지 않습니다.

## 오류 해결

- **AI 연결 안 됨:** `2_START.bat` 창을 켜고 그 창이 연 페이지를 사용하세요. 브라우저의 로컬 네트워크 접근 권한을 확인하세요. `3_OFFLINE.bat`도 사용할 수 있습니다.
- **Python 설치 실패:** python.org에서 Python 3.12 64비트와 Python Launcher를 설치한 뒤 다시 실행하세요.
- **DLL/드라이버 오류:** NVIDIA 드라이버를 업데이트하고 필요하면 Microsoft Visual C++ 2015–2022 재배포 패키지(x64)를 설치하세요.
- **메모리 부족:** 게임·다른 AI 프로그램을 종료하세요. 8GB GPU에서는 실행이 어려울 수 있습니다.
- **AI 파일 없음:** 인터넷 연결 후 `1_INSTALL.bat`를 다시 실행하세요. 이미 받은 파일은 재사용합니다.
- **8765 포트 사용 중:** 이미 열린 AI 창을 확인하세요. 다른 프로그램을 임의로 종료하지 마세요.

## 개발·검증

화면은 외부 CDN·분석 스크립트 없는 HTML/CSS/JavaScript입니다. 백엔드는 Python 표준 HTTP 서버와 FASHN 추론 어댑터입니다. 학습 모델은 저장소에 포함하지 않습니다.

```sh
node --test tests/core.test.cjs
python -m unittest discover -s tests -p 'test_*.py'
```

단위/API 테스트는 GPU 생성 품질을 검증하지 않습니다. 설치 마지막 단계는 해당 PC에서 오프라인 모델 로딩을 확인합니다. 개발 환경에는 NVIDIA GPU가 없어 **실제 가상착용 추론과 Windows 설치 스크립트 실행은 검증하지 못했습니다.** 사용자의 GPU에서 첫 이미지 생성까지 확인해야 합니다.
