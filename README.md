# LOOKBOOK · 관리자 전용 업로드 + 공개 3D 룩북

- **방문자 사이트:** https://mkj5956.github.io/Cookbook-site/
- **관리자 페이지:** https://mkj5956.github.io/Cookbook-site/admin.html
- **Windows 다운로드:** https://github.com/mkj5956/Cookbook-site/archive/refs/heads/main.zip

## 방문자는 이렇게 사용합니다

1. 왼쪽 3개, 오른쪽 3개 의상 중 하나를 선택합니다.
2. 가운데 캐릭터가 해당 의상의 **미리 생성된 3D 착용 모델**로 바뀝니다.
3. 마우스나 손가락으로 좌우로 끌어 360도 회전합니다. 휠·두 손가락으로 확대할 수 있습니다.
4. 캐릭터 아래 `쿠팡에서 보기`를 누르면 관리자가 등록한 상품으로 이동합니다.

방문자에게는 사진 업로드, 파일 수정, AI 연결 버튼이 없습니다. 별도 설치·로그인이 필요하지 않습니다. 휴대폰에서는 3D 캐릭터를 위에, 의상 6개를 아래 두 열에 표시합니다.

아직 공개한 의상이 없으면 **시연용 캐릭터** 6개가 표시됩니다. 이 캐릭터는 프로그램으로 만든 입체 도형이며, 사용자의 사진을 AI로 변환한 결과가 아닙니다. 가짜 상품 링크도 넣지 않았습니다. 관리자 의상을 공개하면 시연용 의상 대신 실제 등록 내용이 표시됩니다.

## 관리자 최초 설정

GitHub Pages는 화면과 파일을 제공하는 정적 호스팅입니다. 서버 비밀번호를 코드에 넣지 않고 **GitHub의 저장소 쓰기 권한**으로 게시를 보호합니다.

1. [관리자 페이지](https://mkj5956.github.io/Cookbook-site/admin.html)를 엽니다.
2. `처음 사용해요 · 인증 코드 만들기`를 펼칩니다.
3. GitHub에서 **Fine-grained personal access token**을 만듭니다.
   - 계정: `mkj5956`
   - Repository access: **Only select repositories → Cookbook-site**
   - Repository permissions: **Contents → Read and write**
   - 나머지 추가 권한은 필요하지 않습니다. 적절한 만료일을 정하세요.
4. 발급된 코드를 관리자 화면에 붙여넣고 `관리자 연결`을 누릅니다.

이 코드는 GitHub 비밀번호와 다릅니다. 코드 자체는 메모리에만 두며 브라우저 저장소·프로젝트 백업·공개 파일에 넣지 않습니다. 새로고침하거나 로그아웃하면 다시 입력해야 합니다. 코드를 채팅이나 저장소에 올리지 마세요.

관리 화면은 `mkj5956` 계정과 저장소 쓰기 권한을 확인한 뒤 열립니다. 공개 페이지 소스를 숨기는 방식이 아닙니다. 외부인이 브라우저에서 버튼을 조작하더라도 GitHub가 유효한 저장소 쓰기 권한 없이 실제 업로드·커밋을 허용하지 않습니다. 저장소에 다른 사람에게 쓰기 권한을 주면 그 사람은 GitHub에서 직접 파일을 바꿀 수 있으므로, 관리자 단독 운영을 유지하려면 저장소 쓰기 권한도 본인만 보유해야 합니다.

## PC에서 사진 → 착용 사진 → 3D 만들기

**무료 로컬 AI** 구성입니다. GitHub는 AI를 실행하지 않습니다. 관리자 PC에서 결과를 미리 생성해 공개하므로, PC를 꺼도 방문자는 공개된 3D 파일을 볼 수 있습니다.

### 필요한 PC

- Windows 10/11, Python 3.11 또는 3.12 (설치 프로그램이 확인합니다)
- NVIDIA RTX 30 시리즈 이상, VRAM 8GB 이상. **12GB 이상 권장**
- RAM 16GB 이상, 디스크 여유 **25GB 이상 권장**
- 최초 설치할 때 인터넷 필요

GPU의 메모리·드라이버·사진에 따라 실행 가능 여부와 속도가 달라집니다. CPU 전용 PC나 스마트폰에서 이 AI 생성기를 실행하는 구성은 아닙니다. 스마트폰에서는 방문자 화면, 관리자 로그인·사진/파일 등록·공개가 가능하지만, PC의 로컬 AI 주소에 직접 연결되지는 않습니다.

### 설치와 실행

1. 저장소 ZIP을 다운로드해 압축을 풉니다. ZIP 내부에서 바로 실행하지 마세요.
2. `local-ai/0_CHECK_PC.bat`로 PC 사양을 확인합니다.
3. `local-ai/1_INSTALL.bat`를 실행합니다. 사진 착용 AI와 3D AI를 모두 설치합니다. 수 GB를 다운로드하며 시간이 걸립니다.
4. `local-ai/2_START.bat`를 실행합니다. 관리자 페이지가 열립니다. 실행 창을 켜두세요.
5. 관리자 인증을 마치고 Chrome에서 로컬 네트워크 접근 안내가 나오면 허용합니다.

이미 이전 사진 합성 버전을 설치했다면 최신 ZIP의 변경 파일을 같은 폴더에 적용한 뒤 `4_INSTALL_3D.bat`를 실행하세요. 폴더를 새로 받았다면 `1_INSTALL.bat`부터 실행합니다.

### 의상 등록과 공개

1. 가운데에 모델의 **정면 전신 사진**을 올립니다. 팔과 다리가 보이고 배경이 단순한 사진이 좋습니다.
2. 양옆 슬롯에 옷 사진, 상품명, 옷 종류, 쿠팡 링크를 등록합니다. 링크는 `https://www.coupang.com/...`, `https://link.coupang.com/...`를 지원합니다.
3. 옷을 클릭하면 **1단계: 옷 입힌 사진 → 2단계: 입체 캐릭터**를 순서대로 생성합니다.
4. `3D 착용 미리보기`를 회전해 확인합니다. 3D 생성만 실패하면 착용 사진은 보관하며 `3D 다시 생성`으로 재시도할 수 있습니다.
5. 완성된 3D 파일이 따로 있으면 `3D 파일 등록`으로 교체할 수 있습니다. 텍스처가 내장된, 추가 확장·압축 없는 **GLB 2.0 / 최대 20MB**를 사용하세요.
6. 등록한 모든 의상이 준비되면 `공개 내용 확인 → 위 내용으로 공개하기`를 누릅니다.
7. GitHub 저장 후 Pages 배포가 완료되면 방문자 사이트에 반영됩니다. 보통 1~3분이며 [Actions](https://github.com/mkj5956/Cookbook-site/actions)에서 확인할 수 있습니다.

`현재 룩에 더하기`를 켜면 이전 착용 결과에 다음 옷을 합성합니다. 게시되는 각 슬롯은 **완성된 전체 착장 한 개**입니다. 방문자가 상의·하의를 독립적으로 실시간 조합하는 옷 시뮬레이션은 아닙니다. 해당 착장에 사용된 상품 링크는 모두 함께 표시합니다.

공개 버튼을 누르기 전에는 사진이 이 브라우저의 작업 공간에 저장됩니다. 공개하면 **상품 사진·착용 사진·3D 파일·상품 링크가 공개 저장소에 저장되고 GitHub 기록에도 남습니다.** 관리자 인증 코드는 업로드하지 않습니다. 원본 모델 사진을 별도 공개 파일로 만들지는 않지만, 공개할 착용 사진과 3D에는 모델의 모습이 포함됩니다.

작업 중에는 `프로젝트 저장`으로 사진·옷·3D 파일을 백업하세요. 브라우저 데이터를 지우거나 다른 기기로 이동하면 작업 초안은 자동으로 옮겨지지 않습니다. 공개 사이트는 GitHub에 저장된 파일을 사용하므로 브라우저 초안을 지워도 유지됩니다.

## 3D 품질과 확인 범위

- **사진 한 장으로 보이지 않는 등·옆모습을 정확하게 알 수는 없습니다.** AI가 형태를 추정합니다. 얼굴·손·무늬·브랜드 로고·옷 뒷면이 부정확하거나 뭉개질 수 있습니다.
- TripoSR는 범용 단일 사진 3D 복원 모델입니다. 정확한 인체 스캔, 피팅 치수 측정, 옷감 시뮬레이션, 움직이는 캐릭터용 뼈대가 아닙니다.
- 기본은 WebGL2 3D 뷰어입니다. 그래픽 기능이 꺼진 기기에서는 실제 메시를 CPU로 그리는 기본 3D 모드를 사용합니다. 기본 모드는 정적·정점 색상 GLB와 최대 16만 면을 지원하며 텍스처·애니메이션·대형 파일은 사진과 호환 안내로 대신 표시합니다.
- 실제 3D 메시를 내보내므로 좌우·앞뒤로 회전할 수 있습니다. 평면 사진을 기울이는 효과로 대체하지 않습니다.
- 고품질 상품용 결과는 앞·뒤 자료를 사용해 만든 전문 GLB 파일로 교체할 수 있습니다.
- 코드·인증·게시·API 계약과 시연용 GLB는 자동 검사를 실행합니다. **이 개발 환경에는 NVIDIA GPU가 없어 실제 사진 합성·3D 추론 및 Windows 전체 설치를 실행 검증하지 못했습니다.** 사용자의 PC에서 첫 생성 검증이 필요합니다.

## 기술 구성

- 공개 화면: 정적 HTML/CSS/JS, Google `model-viewer` 4.4.0 (npm 배포본 무결성 확인, 자체 호스팅, Apache-2.0)
- 관리자 인증·게시: GitHub REST API, 토큰 메모리 보관, 소유 계정 확인, 미디어 해시 파일명, 한 커밋으로 게시, 동시 변경 시 중단
- 사진 착용: [FASHN VTON 1.5](https://github.com/fashn-AI/fashn-vton-1.5), 코드 `7c0f10af3f91ad4048fe9729c470a13ef905d25a`
- 3D: [TripoSR](https://github.com/VAST-AI-Research/TripoSR), 코드 `107cefdc244c39106fa830359024f6a2f1c78871`, [공식 가중치](https://huggingface.co/stabilityai/TripoSR) 고정 버전 사용
- Windows에서 C++/CUDA 추가 컴파일을 줄이기 위해 표면 추출은 scikit-image CPU 어댑터 사용. 추론은 GPU 사용
- 배경 분리: rembg 2.0.67 / u2net_human_seg (로컬 ONNX)
- PC API: `127.0.0.1:8765`만 수신, 실행 때마다 연결 코드 변경, Host·Origin·Bearer 인증, 외부 노출 안 함
- 설치 때 모델을 내려받고 생성 중에는 로컬 파일 사용. 사진은 외부 AI에 전송하지 않음
- GLB의 외부 파일 참조와 확장 압축을 거부해 모델을 읽는 중 임의 외부 요청을 하지 않도록 제한
- 공개 미디어 파일을 교체해도 이전 파일·커밋 기록은 유지. 개인정보를 삭제해야 할 때는 GitHub 기록 정리도 별도로 필요

## 검증 명령

```bash
node --test tests/*.test.cjs
python -m unittest discover -s tests -p 'test_*.py'
python -m compileall -q local-ai
```

Python 테스트는 Pillow가 필요합니다. 테스트는 실제 GPU 추론을 대신하지 않습니다.
